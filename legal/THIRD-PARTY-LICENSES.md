# Browser extension third-party notices

Raindrop is built with Vite. The generated browser bundle can contain Vite's module-preload/runtime helper. Vite's supplied license text is in [Vite-LICENSE.txt](Vite-LICENSE.txt). The extension does not import the documentation site's Vue/VitePress runtime or fonts.

The source project and separately built handbook have a broader dependency inventory and full notices in legal/THIRD-PARTY-LICENSES.md and legal/DEPENDENCY-NOTICES.txt. Third-party libraries keep their own license grants; the Raindrop Terms do not override them. User-added websites, images, scripts and external services have their own rights and terms.
